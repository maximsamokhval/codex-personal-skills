# Розробка та межі персональних skills

## Personal

Персональний skill придатний для повторного використання між різними проєктами, не містить знань конкретного продукту, секретів, приватних endpoint-ів чи локальних конфігурацій.

Його місце:

```text
codex-personal-skills/skills/
```

Приклади:

```text
requirements-extract
requirements-critic
specification-compiler
python-project-harness
```

Перед додаванням перевірте, що skill не залежить від одного репозиторію, клієнта, середовища, облікових даних або недоступних іншим машинам абсолютних шляхів.

## Project-specific

Знання, правила та інструменти, специфічні для одного продукту, не переносять до персонального репозиторію. Їх слід зберігати поряд із кодом проєкту, наприклад:

```text
<project>/.agents/skills/
```

або в іншому project-local шляху, який підтримує поточна версія Codex.

## Робочий процес

1. Створіть або змініть skill у `codex-personal-skills/skills/`.
2. Локально перевірте наявність `SKILL.md` та відсутність secrets.
3. Зробіть один осмислений commit і push.
4. На інших машинах виконайте відповідний `update`-скрипт.

Не вважайте зміни в уже встановленій локальній копії постійними: наступне встановлення замінить лише skill з таким самим ім'ям на версію з репозиторію.
